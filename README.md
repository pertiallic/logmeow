# Logmeow

猫の言語ですにゃ (=･ω･=)

## 使い方

`file`の実行は

`lua logmeow.lua file`

で行えます

オプション`-d`の指定でdebugモードになります 

`lua logmeow.lua file -d (log-file)`

で`log-file`が指定されていたらそのファイルに、そうでなければファイルを作ってそこにdebugのためのlogを流します

オプション`-r`の指定で読みやすい方の書き方で実行できます
