# Logmeow

言語作る会で作った言語ですにゃ (=･ω･=)

## 仕様

この言語は「にゃ」「ー（伸ばし棒）」「ん」を組み合わせて書きます（実はKMCのNFのテーマが「にゃーん」だったりします）

「にゃ」で始まって「ん」で終わり、その中は「にゃ」と「ー」の自由な並びであるようなものがトークンになります

### 数値

Logmeowでは数値を指定することがたくさんあります

基本的に「にゃ」が1で「ー」が0を表す2進数で表現します

自然数（1以上）でなく整数を表現するときは最上位（つまり文字列の中で一番最初のもの）が「にゃ」であれば負の数、「ー」であれば正の数になります
